# Kokoro Bloom

A Next.js + React + TypeScript + Tailwind storefront concept for a luxury floral boutique.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Connect `BTheCoderr/kokorobloom` to Netlify and deploy from `main`. The repository includes `netlify.toml` with the build command and Node 22 setting. Use Netlify's Next.js integration.

## Preview limitations

Products, prices, and photos are illustrative placeholders, not verified business inventory. Cart uses browser local storage. Checkout is intentionally disabled, and the custom bouquet form previews/copies requests without sending or storing them. Add real product photos, verified pricing, inventory, delivery policy, secure payment integration, and order storage before launch.
